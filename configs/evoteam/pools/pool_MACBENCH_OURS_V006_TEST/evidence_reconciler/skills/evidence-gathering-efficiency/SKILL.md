---
name: evidence-gathering-efficiency
description: A checklist for reconciling evidence from task tools quickly under a fixed time/cost budget, avoiding exhaustion from over-exploration.
trigger: When assigned to find, verify, or reconcile records/documents/identifiers under a wall-clock or cost budget.
---
1. First call: discover tool names and schemas in ONE batch (list_tools, then describe the few you need together) — do not describe tools you will not use.
2. Identify the 2–3 core records that answer the assigned question, fetch them in a single parallel batch.
3. Write down what you have (record IDs, key values, conflicts) after the first batch — do not defer reporting.
4. Send a concise partial-findings report to the requester early: finding, source IDs, conflicts/uncertainty, what remains. This unblocks downstream work; you can refine in parallel.
5. Only after the partial report, chase secondary/edge records IF the requester still needs them.
6. Hard time-box: if you have done ~3–5 tool batches and still lack a complete picture, STOP exploring and report current state with explicit gaps. A delivered partial answer beats a terminated task.
7. Keep messages short and fact-dense: bullet the evidence, avoid prose narration of your exploration.
